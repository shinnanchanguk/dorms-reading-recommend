# 이 책의 모양 지키기

학생 도서 추천 화면이 독서 교육 책의 다른 칸(앱과 자료 · 생각 나누기 · 기여도)과 같은 책으로 보이게 하는 규칙입니다.
구조를 바꿔도 아래만 지키면 같은 책처럼 보여요. 모양 자체를 바꾸고 싶으면 바꿔도 됩니다. 다만 맨 아래 '바닥 규칙'은 지켜 주세요.

실제 값은 `dist/style.css` 에 있고, 새 화면에 옮겨 쓰기 쉬운 최소 묶음은 `design/book-look.css` 에 있어요.

## 색

- 바탕 · 글자 · 선은 도름스가 건네는 책 색을 씁니다. 화면 맨 위에서 `dorms.applyTheme(theme)` 를 부르면 아래 이름으로 들어와요.
  - `--paper` 종이(바탕) · `--ink` 글자 · `--ink-light` 흐린 글자 · `--border-light` 얇은 선 · `--border-dark` 진한 선
- 교과 색은 `ReadingPalette.apply(theme)` 가 만드는 `--ch-1` ~ `--ch-10` 입니다. 무엇이든 `data-chapter="1"`~`"10"` 을 달면 `--chapter-color` 로 받아요.
  01 공통 · 02 국어 … 순서로 1번부터 돌고, 열한 번째 교과부터 다시 1번 색을 씁니다(책의 목차와 같은 규칙).
- 옅은 바탕은 `color-mix(in srgb, var(--chapter-color) 6~11%, var(--paper))` 처럼 섞어서 만듭니다.

## 글자

| 자리 | 글꼴 | 크기 · 굵기 |
|---|---|---|
| 화면 제목 | 명조(`--rr-display`) | 28px · 600 (폰 24px) |
| 교과 이름 | 명조 | 18px · 600, 펼치면 700 (폰 17px) |
| 책 제목 | 명조 | 17px · 700 |
| 본문 · 추천 이유 | 고딕(`--rr-sans`) | 15~16px · 줄 간격 1.6~1.7 |
| 보조(지은이 · 학년 · 개수) | 고딕 | 13px · 흐린 글자 |

글꼴 파일은 바깥에서 받을 수 없어 기기에 있는 명조 · 고딕을 차례로 씁니다. 꼭 같은 글꼴이 필요하면 woff2 파일을 `dist` 안에 넣으세요(파일 하나 2MB까지).

## 모양

- **번호 표식**: 32×32, 모서리 8px, 교과 색 바탕에 종이색 글자 13px 굵게("01").
- **교과 줄**: [번호 표식][교과 이름 · 한 줄][개수 알약][꺾쇠] 네 칸, 높이 56px 이상, 줄 사이 얇은 선.
- **비어 있는 교과**: 번호는 테두리만, 이름은 흐린 글자, 개수 알약은 감춰 채운 교과가 먼저 읽히게 합니다. '함께 채울 자리'라고 적어요.
- **펼친 교과**: 번호 아래에서 교과 색 줄기(2px)가 내려와 책이 매달립니다.
- **단추**: 모서리 8px, 높이 40px 이상(폰 44px), 테두리 단추 · 먹색 바탕 단추 · 테두리 없는 작은 단추 세 가지.
- **카드 · 상자**: 모서리 14px, 그림자보다 얇은 선으로 나눕니다.

## 바닥 규칙(바꾸지 않아요)

- 쌩 흰색(#fff) 바탕을 쓰지 않습니다. 밝은 화면도 종이색이에요.
- 화면 기호는 SVG 로 그립니다(이모지 · 문자 기호 금지).
- 한글은 `word-break: keep-all`, 넘치는 글은 `overflow-wrap: break-word`. `anywhere` 는 글자를 한 글자씩 세로로 쌓이게 해서 쓰지 않아요.
- 긴 줄표 대신 쉼표 · 마침표 · 가운뎃점으로 씁니다.
- 밝은 화면과 어두운 화면 둘 다에서 읽히는지 연습용 도름스의 '색'을 바꿔 확인합니다.
