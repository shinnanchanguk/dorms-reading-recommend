# 학생 도서 추천 (도름스 독서 교육 책)

도름스 서재의 **독서 교육** 책 안, **학생 도서 추천** 칸에 실리는 화면의 레포입니다.
운영하는 선생님이 교과마다 학생에게 권하는 책을 원하는 모양으로 꾸미고 담습니다.

처음이라면 쓰는 AI 에게 이렇게 말하세요.

> "dorms-reading-recommend 레포를 내려받고 시작하기.md 를 읽고 그대로 나를 안내해 줘"

## 한눈에

- 화면은 `dist/` 안의 HTML · CSS · JS 입니다. 지금 들어 있는 교과별 목록은 출발점이고, 구조는 마음대로 바꿔도 됩니다.
- 화면은 도름스 안의 **격리된 액자**에서 돕니다. 도름스 로그인 정보나 데이터베이스에는 닿지 않고, 필요한 것은 책 SDK 로 물어봅니다.
- 추천 도서 같은 기록은 책의 **데이터 상자**에 담습니다. 어떤 자료 표(모음)를 쓰는지는 `dorms-book.json` 의 `data` 에 적어 둡니다.
  새 판을 승인할 때 도름스 운영자가 이 선언을 보고 실제 저장소에 연결합니다.
- 새 판은 도름스 운영자가 승인한 뒤 책에 실립니다. 언제든 예전 판으로 되돌릴 수 있어요.

## 명령

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 연습용 도름스를 띄웁니다. `http://127.0.0.1:4410/mock-host/` |
| `npm run check` | 새 판을 내기 전 점검(묶음 규칙 · 자료 표 선언 · 열쇠나 개인정보가 섞이지 않았는지) |

설치할 것은 없습니다(node 18 이상만 있으면 돼요).

## 폴더

| 자리 | 내용 |
|---|---|
| `dist/` | 도름스에 실리는 화면. `index.html` 과 `book.manifest.json` 이 맨 위에 있어야 해요 |
| `dist/dorms-book-sdk.js` | 도름스 책 SDK(도름스가 주는 원본, 고치지 않아요) |
| `dist/palette.js` | 책과 같은 교과 색을 만드는 작은 도구 |
| `dist/fit.js` | 액자 높이를 내용에 꼭 맞추는 작은 도구(접으면 줄어들어요) |
| `dorms-book.json` | 레포 확인 코드와 자료 표 선언 |
| `mock-host/` | 연습용 도름스(가짜 데이터, 손님부터 운영하는 분까지 자리 바꿔 보기) |
| `design/` | 이 책의 모양을 지키는 규칙 |
| `scripts/` | 연습용 서버와 점검 |
| `AGENTS.md` | AI 가 지킬 규칙 |
| `시작하기.md` | 선생님 옆에서 AI 가 따르는 안내 대본 |
