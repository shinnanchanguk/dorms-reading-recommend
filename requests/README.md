# 변경 요청 파일

이 폴더의 `.md` 파일 하나가 도름스 운영자에게 가는 변경 요청 하나예요. 보통은 AI 가 아래 명령으로 만들어 올려요.

```bash
node scripts/dorms.mjs request "요청 제목" --kind 화면
```

손으로 만들 때는 이 모양을 지켜 주세요.

- 파일 이름: 영문 · 숫자 · `.` `-` `_` 만, 날짜로 시작(예: `2026-10-06-grade-list.md`). 한글 제목은 파일 안에 적어요.
- 맨 위 세 줄

```text
---
제목: 학년별로 나눈 추천 목록
종류: 화면
---

무엇을 왜 바꿨는지, 화면 어디를 보면 되는지 적어요.
```

- 종류: `화면` · `기능` · `데이터` · `기타`
- 열쇠 · 토큰 · 비밀번호 · 학생 개인정보는 적지 않아요. 이 레포는 공개 레포예요.
- 한 번 올린 요청 파일은 고치지 말고, 보완할 때는 새 요청을 올려요.

도름스가 10분마다 이 폴더를 보고 새 파일을 접수해요. 결과는 `npm run status` 로 봐요.
